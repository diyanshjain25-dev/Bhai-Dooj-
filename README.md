## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/diyanshjain25-dev/Bhai-Dooj-.git
   cd Bhai-Dooj-
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Run the project locally
   ```bash
   npm start
   ```
